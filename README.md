# Object-Oriented Programming (OOP) Course Tasks

This repository contains my university assignments and practical tasks for the **Object-Oriented Programming (OOP)** course.  
The purpose of this repository is to document, implement, and submit coursework related to object-oriented design and programming principles.

---



The Object-Oriented Programming course focuses on designing and building software using object-oriented concepts and principles.

Throughout this course, the tasks cover:

- Classes and Objects
- Constructors and Destructors
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism
- Method Overloading & Overriding
- File Handling
- Exception Handling
- Basic Design Principles

---



Each folder represents a specific assignment or task.
